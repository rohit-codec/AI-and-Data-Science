# 📁 Folder Management Rules

The repository follows a simple hierarchy:

```text
Phase
  ↓
Library / Topic
  ↓
Subtopic
  ↓
Notes / Code / Notebook
  ↓
Projects
```

For example:

```text
Phase-2-Python-Libraries/
│
└── NumPy/
    │
    ├── 01-Basics/
    │   ├── notes.md
    │   └── basics.ipynb
    │
    ├── 02-Arrays/
    │   ├── notes.md
    │   └── arrays.ipynb
    │
    ├── 03-Indexing-and-Slicing/
    │
    └── Projects/
        └── numpy-project.ipynb
```

### Naming Convention

Use:

```text
01-Topic
02-Topic
03-Topic
```

for topics that have a natural learning order.

Use clear names such as:

```text
NumPy
Pandas
Matplotlib
Machine-Learning
Deep-Learning
Generative-AI
```

for major subjects.

# 💻 Git Workflow

This repository uses the `main` branch for the learning journey.

After making changes:

```bash
git status
```

Add changes:

```bash
git add .
```

Commit:

```bash
git commit -m "Add NumPy array basics"
```

Push:

```bash
git push origin main
```

Before starting new work, it is good practice to get the latest changes:

```bash
git pull origin main
```

### Basic workflow

```text
git pull
   ↓
Learn / Code / Practice
   ↓
git status
   ↓
git add .
   ↓
git commit
   ↓
git push
```
